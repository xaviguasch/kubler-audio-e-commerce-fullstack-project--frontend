# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/your-username/kubler-audio.git
```

## 2. Navigate into the Project

```bash
cd kubler-audio
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Run the Development Server

```bash
npm run dev
```

## 5. Open in Browser

```bash
http://localhost:3000
```
